# Smart Career Compass

Create a modern web platform called "Smart Career Center PEDULI".

This is a career center system for students, alumni, and partner companies.

Design Style:

- modern SaaS dashboard

- clean UI

- glassmorphism

- 3D illustrations

- responsive design

- smooth animations

Color palette:

Emerald green #10B981

Navy blue #1E3A8A

Light background #F8FAFC

Typography:

Headings: Poppins

Body: Inter

Main Pages:

1. Landing Page

Hero section with headline:

"Smart Career Center PEDULI – Masa Depan Karier Santri Dimulai Disini"

Include statistics:

- total alumni

- total job vacancies

- partner companies

- scholarship programs

Include 3D illustrations of career growth and digital dashboard.

2. Dashboard

Modern admin dashboard with cards showing:

- total alumni

- active job vacancies

- partner companies

- scholarship programs

Include charts:

- alumni career distribution

- job placement statistics

3. Job Portal

Features:

- search job

- filter by location

- filter by job type

- job details

- apply button

4. Alumni Database

Features:

- alumni profiles

- graduation year

- company

- job position

- tracer study tracking

5. Partner Companies

Companies can:

- post job vacancies

- join campus hiring

- participate in career fairs

6. Career Events

List events such as:

- seminars

- workshops

- career fairs

- company talks

7. Admin Panel

Features:

- manage alumni data

- validate job postings

- manage partner companies

- upload career content

Additional Features:

- email notifications

- job alerts

- mobile responsive

- authentication login system

- modern UI components
